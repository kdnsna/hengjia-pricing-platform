# 衡价 · 全员全产品计价系统

面向银行全员全产品计价的全栈工作台。内置用户提供的2026年计价标准51项，其中利润20项、规模11项、客户20项；个金27项保留明确提供的M码关联。

## 功能

- 经营总览：机构、产品类别、期间进度与异常概览。
- 计价规则：搜索筛选、单价维护、算法与取数关联、CSV导出。
- 计价试算：直接计价、存量逐月、时间加权、季度折算、封顶保底、正负增与零值处理。
- 业绩归属：多人/跨机构比例分润、依据留痕、比例合计预警。
- 异常校验：单价、引用断链、月份残留、重复计价、指标缺失与零值分支。
- 审核版本：草稿、复核、锁定、结果快照、操作日志与凭证导出。

## 运行

```bash
npm install
npm run db:push
npm run dev
```

生产验证：`npm run check && npm run build && npm start`。端口固定为3000。

## 数据与边界

数据通过tRPC与Drizzle持久化到平台MySQL。当前人员、机构积分及批次数字为演示数据；年度单价来自用户提供的扫描件。未提供的核心系统接口以可配置取数映射表示，不表示已联通生产源系统。

## 验收

`verifier/v1/`包含业务引擎与真实浏览器验收脚本；运行记录和桌面/移动端截图保存在`verifier/runs/`。
