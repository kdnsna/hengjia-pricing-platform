# V1 验收标准

## 业务完整性
- 年度单价底表完整覆盖扫描件中的利润、规模、客户三类指标，保留存量/总量、正增长、负增长与计价单位。
- 个金指标保留 M 码、口径、取数与积分关联；支持直接乘数、存量逐月、时间加权、季度折算、正负分支、封顶/保底、零值与缺失数据处理。
- 支持组织、人员、岗位/身份、产品归属、按比例分润、跨机构协作、调整冲正、补录追溯。
- 支持草稿、试算、复核、审批、锁定、版本快照与操作日志。

## 可运行功能
- 总览、规则中心、计价试算、业绩归属、异常校验、审核版本均可通过导航访问。
- 可修改试算月份和输入值，结果按规则实时重算且展示计算过程。
- 可新增分润并校验比例合计；可提交审批、审批并锁定；数据通过真实后端与数据库持久化。
- 规则搜索、分类筛选、异常筛选、导出均有实际行为；无空按钮和占位链接。

## 工程质量
- TypeScript 检查及生产构建零错误。
- 后端接口真实读写成功，生产入口为 dist/boot.js。
- 桌面 1440px 与移动 375px 无横向页面溢出；主要交互可点击/键盘访问，触控目标不小于 44px。
- 浏览器无控制台错误、无 404；关键页面与弹层实际截图检查。

## 边界
- 系统内置数据明确标注为演示数据；未提供的源系统接口采用可配置取数映射，不虚构已联通核心系统。
- “完整”指本次材料覆盖范围与通用计价场景完整，不宣称未提供的行内制度已自动获得。
