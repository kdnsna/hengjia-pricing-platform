# V5 验收标准：全产品计价系统办理闭环

日期：2026-10-26。V5 保留 V1—V4 的指标、公式、权限、批次和建设方案要求，新增本轮实际改动的验收，不覆盖历史验收文件及运行记录。

## 产品名称与展示

- 登录页、侧栏、浏览器标题、README 和 favicon 统一使用「全产品计价系统」与品牌字「计」。
- 当前源码和验收脚本不再出现「衡价」或单字品牌「衡」。历史运行证据不篡改，仓库地址和会话 Cookie 等技术标识可保留。
- 桌面侧栏、登录页和 375px 移动布局不截断七字产品名称。

## 批次明细、退回与审批

- 有批次查看权限的岗位可查看权限范围内的明细；普通员工和客户经理仍无正式批次查看权限。
- 明细至少包含人员、机构、产品、规则版本、业务输入、计算过程、单项积分和规则定义快照；历史不完整快照不得导致页面异常。
- 明细 CSV 与页面使用同一批次快照，包含计算输入、表达式和积分，不只导出汇总状态。
- 仅复核人员可退回复核中批次，退回原因为 4—500 字；提交人不能退回或审批本人批次。
- 退回后恢复草稿并保留退回人、原因和时间；有保存权限的岗位可编辑批次名称与业务输入，服务端重新复算明细、人数和总积分后才能重新提交独立复核。
- 复核中及已锁定批次不能编辑；重复退回、重复提交、重复审批及锁定后退回必须被服务端拒绝，状态更新使用条件校验。
- 修改、提交、退回、重新提交和审批均保留操作日志，锁定结果不可被编辑或退回操作改写。

## 本人分润确认

- 待确认记录只能由 `employeeId` 与当前登录人一致的归属人确认；管理员、机构负责人、客户经理和同事均不能代确认。
- 确认弹窗展示期间、产品、人员、比例和依据；确认后保存确认人、确认时间和状态并刷新待办。
- 重复确认返回状态冲突且不重复写审计记录。
- 数据库存储的 `approved` 状态在界面表达为「已确认」，不代表薪酬审批、完整绩效结果发布或放弃异议权利。

## 期间与积分口径

- 顶部期间选项包含业务数据已有期间；分润分组、批次列表和对应导出随所选期间变化。
- 工作台主积分只汇总当前期间已锁定批次；草稿和复核中批次只单独计数，不混入已锁定积分。
- 建设方案明确本轮具备分润本人确认，完整结果发布、员工申诉、HR／SSO、薪酬支付和监管报送仍为未交付能力。

## 工程与真实验收

- `npm run check`、`npm test`、`npm run lint`、`npm run build` 全部通过。
- 新增业务守卫单元测试和 V5 真实接口验收，覆盖权限、状态、审计、重复操作和数据范围。
- 使用真实浏览器完成品牌、明细、退回、重报、审批、本人确认、期间筛选、锁定积分和 CSV 导出检查。
- 1440、1024、768、375 像素无页面横向溢出；375 像素主要操作按钮不小于 44px；关键截图逐张查看。
- 无未预期控制台错误、页面异常、资源 404 或失败响应。
- 使用独立测试指标、批次和分润，不清库、不删表、不删除既有业务数据；测试指标完成后停用并保留记录。
